# Mohammed Nadjib Salmi — Portfolio

Personal portfolio for Mohammed Nadjib Salmi, a network and distributed systems engineer interested in reliable software, system architecture, and applied technology.

## About this repository

This is a lightweight static website built as a single HTML page. It can be opened directly in a browser or served by any static web server.

## Run locally

Open `index.html` in a browser, or serve the repository with any static server:

```bash
npx serve .
```
